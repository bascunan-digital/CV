## Convención de cifras

Las cifras entre corchetes, como **`[35%]`**, son **estimaciones de referencia que tienes que validar** antes de enviar el CV.
Cámbialas por el dato real o quita la cifra. En una entrevista te van a pedir que expliques cada número.
Las cifras sin corchetes vienen del CV base (4.9/5 con 38 reseñas, 2010–presente, etc.).
