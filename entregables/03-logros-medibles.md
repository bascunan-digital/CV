# 3. Potenciador de logros medibles

## Fórmula

**Verbo de acción + Qué hiciste + Cómo (stack/método) + Resultado medible**

Métricas que pesan en un perfil UX/UI + Front-End:
- **Tiempo:** días de entrega, horas ahorradas, ciclos de revisión.
- **Calidad:** puntaje Lighthouse, Core Web Vitals (LCP/CLS/INP), bugs en QA, cumplimiento WCAG.
- **Negocio:** conversión, reservas, leads, retención, tickets de soporte.
- **Escala:** número de proyectos, clientes, usuarios, colegios, visitantes.

> ⚠️ **Cómo validar cada cifra `[ ]`:** revisa Google Analytics o Search Console, el historial de facturas o tickets (La Vitamina), exportaciones de la base de datos (reservas de Valeria), las fechas de commits en Git o una estimación razonable que puedas explicar ("de ~5 días a ~2 días por landing, según mis registros de horas"). **Si no puedes justificar un número, usa una métrica de escala** ("40+ proyectos") en vez de un porcentaje.

## Verbos de acción recomendados (en vez de "responsable de", "encargado de", "participación en")

**Liderazgo:** Lideré · Dirigí · Definí · Estandaricé · Capacité · Mentoricé
**Impacto:** Reduje · Aumenté · Aceleré · Eliminé · Escalé · Logré
